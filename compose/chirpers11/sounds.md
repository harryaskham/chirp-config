# Escapement (chirpers11): the sound bank

Clicky minimal techno: few sounds, each one designed. Add every new patch, kit, bus and recipe to the table as you make it: name, what it is, what it was built from, where it lives. New names only: released albums render through the library, so never edit a patch another record uses (`tools/libguard.py`). Song-local patches (in a song's own `patches:`) are free; say when one is worth banking.

## Recipes

| recipe | how | who |
|---|---|---|
| A PART ON ANOTHER CLOCK: one function d(t) (beats ahead of the grid) places every event of a part (`t + d(t) = b`, solved by iteration) and tunes it (`12 log2(1 + d')` on a lane into `synth.pitch.mod`) | `compose/chirpers11/src/chirpers11-t1.py`: `d`, `when`, `speed`, `spd_lane`, `deck_b` | chirper-zero, t1 v1 |
| A FORM FROM LEAST COMMON MULTIPLES: give each part a cycle, and place every event of the form where cycles meet (`s % c == 0` for two, for three, for three and the beat, for all and the bar); nothing is typed as a bar number, and changing one cycle rewrites the song | `compose/chirpers11/src/chirpers11-t2.py`: `CYCLES`, `SUPER`, `PAGE`, `HALF`, `build`; `euclid` for the fills | chirper-one, t2 v1 |
| A ROOM OF TWO WALLS (a room is a rhythm): two buses, each with `returns` from the source (`-4dB`) and from the OTHER wall (`-3dB`) at its own distance (`time: "3/16"` and `"4/16"`), an eq for what the wall absorbs, then a door bus (pan, a `gain` on a lane). The echoes fall at a, b, a+b, 2a+b, a+2b, 2(a+b) ...; read in a bench to the sixteenth. A room whose length divides the bar stands; one that does not fills the bar. A source that repeats every bar sounds the same every bar in ANY room: to hear the room's cycle against the bar, strike on the room's own time | `compose/chirpers11/src/chirpers11-t3.py`: `ROOMS`, `buses()`, `tock_notes()` | chirper-zero, t3 v1 |
| A CLICK IS A NOTE STOPPED TOO SOON: give a struck model its ring time per stroke (`decay: {value: t0, mod: [{src: expr.ring, amount: 1}]}`, the note carrying `expr: {ring: seconds}`), hold the amp envelope open, and write the form as each thing's ring against the bar. Read each thing on a bench first (`--bench`: one stroke at six rings; fall time, strongest partial, share of power on the note) | `compose/chirpers11/src/chirpers11-t4.py`: `RING`, `SHAPE`, `ring_at`, `seconds`, `CAL`, `EASE`, `bench` | chirper-one, t4 v1 |
| A RISSET RHYTHM (an accelerando that never arrives): L layers, each twice as fast as the one below; stroke n of the finest falls at `T * log2(n / n0)` for n = n0 ... 2 n0 - 1 (n0 = C * 2^(L-1)); a stroke belongs to layer j when `n % 2^(L-1-j) == 0`; velocity = the sum of its layers' windows `sin^2(pi * (t / T + j) / L)` over L / 2, on a patch with `vel_sens 1`. The row repeats exactly (measured 1.000) while every layer doubles its speed. Choose C near `T / (2 ln 2)` (23 for 32 beats) and the layers start and end each row on the grid | `compose/chirpers11/src/chirpers11-t5.py`: `risset`, `ris_notes` | chirper-zero, t5 v1 |
| A COMB WITH NO EFFECT, AND A PUMP WITH NO COMPRESSOR (phase as the only tool). Comb: two tracks, one patch with no noise and a fixed start phase (`saw phase=0`), the same notes a few ms apart: notches at odd multiples of 1 / (2 gap), +6 dB at multiples of 1 / gap (measured). Pump: pairs of `sine phase=0` whose frequencies differ by one cycle a beat (`ratio = h + (BPM / 60) / f0`), struck on the off-beat: they cancel on every beat | `compose/chirpers11/src/chirpers11-t7.py`: `phi`, `when`, `b_notes`, `os-click`, `os-bass` | chirper-zero, t7 v1 |
| A PAIR OF COINS (an echo network that composes): two buses that `returns` a seed track, themselves and each other, each with `pitch` in the loop; an echo lands `p*a + q*b` steps late and `7*a - 5*b` semitones off. THE `pitch` EFFECT IS LATE: with its default grain about 14 ms a pass shifting up a fifth (11 to 18) and 18 ms down a fourth, and it peaks unevenly after several passes; with `grain 10ms` 3 to 5 ms a pass; with `grain 80ms` it wanders by tens of ms. Take the lateness off the return's time (written in ms) | `compose/chirpers11/src/chirpers11-t6.py`: `PAIRS`, `LAG`, `G`, `lattice`; bench tools in the composer's notes | chirper-one, t6 v1 |
